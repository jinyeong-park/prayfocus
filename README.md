# PrayFocus

> When notification hits, you pray. No swipe away.

A minimalist prayer companion app built with React Native (Expo). 
Inspired by Luts' Pray Screen model: friction-as-a-feature.

## Core mechanic

1. Set your daily prayer time  
2. At that time, your phone prompts you to pray  
3. Hold for 3 seconds to begin  
4. 60-second prayer timer locks the screen  
5. Build your streak

## Tech stack

- React Native (Expo SDK 51)
- Reanimated 2
- Expo Notifications
- AsyncStorage

## Run locally

```bash
npm install
npx expo start
```
